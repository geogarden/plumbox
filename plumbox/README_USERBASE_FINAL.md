# PlumBox GPT SOL 1

Projekt zachowuje układ graficzny wywodzący się z USERBASE v10, lecz frontend i backend zostały zmienione. Nie jest to kopia 1:1 dawnej paczki.

Obsługiwane sposoby pracy:

- natywna usługa na Orange Pi/Debian/Armbian,
- lokalna aplikacja Home Assistant,
- połączenie TCP, serial albo jawny tryb `simulation`,
- profile `fixed_ecomax860p4` i `auto_detect`.

Przed instalacją przeczytaj właściwą instrukcję oraz [START_TUTAJ_DLA_NOWEGO_AI.md](START_TUTAJ_DLA_NOWEGO_AI.md). Brak testu na fizycznym sterowniku oznacza, że wariant ma status eksperymentalny, a zapisy `advanced/critical` są zablokowane.
